# 海钡合同样式规范（可移植副本）

本规范依据 `海钡通用合同模板_英文中文.docx` 提取；母版基线 SHA-256 为 `C288DA1BC2B8FCB9FA71A39EB3EE024B98E5CC8AD67203D7264CF3353C1D16E6`。它适用于海钡人力的招聘、猎头、EOR、派遣、咨询、培训、平台、合作及其他业务合同。用户确认的法律与商业内容优先，但不得破坏以下视觉系统。

## 证据基线

- 全局视觉母版：`海钡合同撰写/海钡通用合同模板_英文中文.docx`。
- 母版 SHA-256：`C288DA1BC2B8FCB9FA71A39EB3EE024B98E5CC8AD67203D7264CF3353C1D16E6`。母版哈希变化时，本规范中的尺寸、字体和组件数据必须重新核验，不得继续沿用旧记录。
- 母版为 1 个 Letter 纵向节：页面 8.50 × 11.00 英寸；左/右边距 0.50 英寸，上/下边距 0.45 英寸；页眉/页脚距边界 0.35 英寸；首页不启用独立页眉页脚。
- 本规范记录的是从母版 DOCX 的段落、运行、表格、节和页眉页脚结构中提取的可复现值。截图、PNG 和 PDF 仅可用于最终渲染 QA，不是布局规则的来源。

## 内容与版式角色

- 首页标题块按以下顺序保留内容角色：中文合同名、英文合同名、双语版本说明、版本说明、主体信息栏、`Party Information | 当事方基本信息`。
- 正文内容按“章节标题 → 英文主段 → 同编号中文对照段”顺序组织；每个实质性条款必须保留同一编号，不能把主语言和对照语言拆到不同编号或不同语义段。
- 合同模板中的双方主体信息、注册号、地址、联系人、邮箱、生效日和合同编号属于首页元数据槽位；未确认值使用明确占位符，不用推测值填充。
- 服务范围、交付、费用、税费、付款、保证期、期限终止、责任与合规、适用法律、争议解决、附件和签署信息属于业务内容槽位；多语言技能只负责语言配对和版式继承，不擅自改变法律或商业内容。
- 签署页保留双方名称、盖章、授权代表签字、联系人、联系方式和签署日期；签署表不得被压缩成无标签的空白表格。

## 首页、正文和语言对照

- 首页顶部主体栏为 1 行 3 列，表格网格总宽 10,800 twips，网格列为 3,600 / 3,600 / 3,600；实际首行单元格宽度为 4,080 / 1,200 / 4,080 twips。左右主体居中加粗，中间单元格保留合作符号位置。
- 首页标题区的正文样式以母版运行格式为准：中文主标题为 SimHei 22 pt、加粗、`#0B2545`、居中；英文主标题为 Calibri 16 pt、加粗、`#1F4D78`、居中；双语版本说明为 Calibri + SimSun 10.5 pt、斜体、`#666666`、居中；版本说明为 Calibri + SimSun 9.5 pt、`#666666`、居中。
- 首页当事方信息表为 6 行 × 4 列；表格网格为 2,700 / 2,700 / 2,700 / 2,700 twips。每个标签单元格宽 1,650 twips、值单元格宽 3,030 twips；标签格填充 `#F2F4F7`，值格白底。六行依次承载双方名称、注册号、地址、联系人、邮箱，以及生效日/合同编号。不得用未经母版证据支持的“截图混合网格”替代此结构。
- 章节标题使用 `English title | 中文标题` 或目标语言对应的双语标题，Calibri + SimSun，15 pt，加粗，`#2E74B5`；段前约 14 pt，段后约 7 pt，行距约 1.08 倍。章节标题沿用 Normal 段落中的直接格式，不强制改造成另一个 Word 内置标题样式。
- 英文主段使用 Calibri 10.5 pt、黑色、首行悬挂结构（左缩进约 0.32 英寸、首行约 -0.32 英寸）、段后约 0 pt、1.10 倍行距；编号运行可加粗，其余正文不加粗。
- 中文对照段使用 SimSun（East Asia）10.5 pt、`#404A6B`、左缩进约 0.18 英寸、段后约 6-7 pt、1.15 倍行距；段落底色为 `#EEF3FF`，左侧为 `#2E74B5` 单线，OOXML 边框宽度为 16 eighths of a point。蓝底必须覆盖完整对照段落，不能只给个别字符或单行着色。
- 其他语言沿用其在保留多语言参考 DOCX 中实际使用的语言字体；例如泰文主段使用 Leelawadee UI 10.5 pt，中文对照仍使用 Calibri + SimSun 10.5 pt / `#404A6B`。语言字体、编号和对照顺序以参考 DOCX 的实测结果为准，不以机器默认字体替代。

## 表格、签署和附件

- 新表格一律固定布局；金额、百分比、日期、周期和短字段水平、垂直居中，长说明可左对齐。未知商业数据只能用业务占位符。
- 保证期单位放在表头，数据格仅放数字。任何报价表须明确币种、税费口径、付款节点和适用条件。
- 签署页使用标题、英文声明、中文浅蓝对照声明及 6 × 2 签署表。签署表总宽 10,800 twips、两列各 5,400；首行列示双方名称，后五行依次为盖章、签字、联系人、联系方式、日期。首行标签格填充 `#F2F4F7`；声明和整张表不能拆页。
- 每项附件独立起页，附件标题沿用章节标题；图片保持纵横比，不裁切或拉伸。

## 输入和交付核验

在生成前收集合同类型/语言、双方主体、服务范围/交付/验收、费用税费付款、期限终止、责任与合规条款、适用法律争议解决、附件和签署信息。缺失项以清楚占位符表示，不作推断。

交付前重新打开 DOCX，核对所有条款、金额、日期、双方名称、表格、附件和页眉页脚，并排除 `FORMTEXT` 等技术字段。使用 Office 渲染器导出 PDF/PNG，逐页检查封面、正文、费用表、签署页及附件；发现缺字、错配、溢出、截断、表格错位或异常空白后，修复并重新完整渲染。
